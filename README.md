# Student CRUD REST API — Django + SQL

A basic CRUD REST API built with Django, Django REST Framework, and SQLite (an SQL relational database).

## Features
- Create, list, retrieve, update, and delete student records
- Input validation through a DRF ModelSerializer
- Unique email constraint
- Django admin integration
- Four basic API tests
- Browsable API for manual testing

## Requirements
- Python 3.10+
- pip

## Setup (Windows PowerShell)

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py makemigrations students
python manage.py migrate
python manage.py runserver
```

Open `http://127.0.0.1:8000/api/students/`.

## API endpoints

| Method | URL | Action |
|---|---|---|
| GET | `/api/students/` | List all students |
| POST | `/api/students/` | Create a student |
| GET | `/api/students/1/` | Retrieve one student |
| PUT | `/api/students/1/` | Replace a student's fields |
| PATCH | `/api/students/1/` | Update selected fields |
| DELETE | `/api/students/1/` | Delete a student |

## Example POST request

Send `POST http://127.0.0.1:8000/api/students/` with JSON body:

```json
{
  "name": "Kartik Bais",
  "email": "kartik@example.com",
  "course": "Computer Science Engineering"
}
```

Example successful response (the `id` and `created_at` values are generated by the server):

```json
{
  "id": 1,
  "name": "Kartik Bais",
  "email": "kartik@example.com",
  "course": "Computer Science Engineering",
  "created_at": "2026-10-24T..."
}
```

## Run tests

```powershell
python manage.py test
```

## Important notes
- This is a learning project. The API currently allows unauthenticated access so it is easy to practise. Do not deploy it publicly as-is.
- For production, use a secret key from environment variables, set `DEBUG=False`, configure allowed hosts, add authentication/permissions, and use a production database configuration.
- SQLite is SQL. You can later switch the Django database settings to PostgreSQL or MySQL.
